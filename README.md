## 🚀 Featured Project

<div align="center">

### 🛰️ Project Parali

**Satellite AI for Agri-Waste to Biomass**

<a href="https://project-parali-1.onrender.com">
<img src="https://img.shields.io/badge/🌐_LIVE_DEMO-Visit_Project-16A34A?style=for-the-badge" alt="Live Demo"/>
</a>
<a href="https://github.com/azizulbuilds/Project-Parali">
<img src="https://img.shields.io/badge/💻_SOURCE_CODE-GitHub-6366F1?style=for-the-badge" alt="Source Code"/>
</a>

</div>

**The problem:** Crop-residue burning contributes to severe air pollution across parts of North India, while biomass facilities need better information about where and when agricultural residue may become available.

**The idea:** Use satellite signals and machine learning to help turn agricultural waste into a potential biomass resource.

**What I'm exploring:**

* 🛰️ Satellite imagery analysis using Sentinel-2 data.
* 🌱 Vegetation intelligence with indicators such as NDVI.
* 🔥 Satellite-based crop-burn detection using RGB and SWIR imagery.
* 🧠 Deep learning with PyTorch and computer vision models.
* 🗺️ Field-level analysis and map-based intelligence.
* 🌾 Connecting agricultural residue insights with biomass opportunity planning.

**Tech behind the project:**

`Python` `PyTorch` `FastAPI` `React` `Satellite Imagery` `Google Earth Engine`

> Building technology is exciting. Building technology around a real-world problem is even better.
